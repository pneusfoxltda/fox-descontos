# FOXNET · Sistema Integrado Rede Fox Pneus

Intranet e sistemas da Rede Fox Pneus: FOXNET, App de descontos, Cadastrar desconto,
Consulta e Painel do televendas, com a assistente Fernanda.

- Intranet: https://foxnet-intranet.vercel.app/
- Sistemas: https://fox-descontos.vercel.app/

Tudo sobre o projeto (estrutura, decisões, login e níveis, próximos passos) está em
[`CLAUDE.md`](CLAUDE.md).

Desenvolvimento: `npm install`, `npm run dev`; publicação automática pelo Vercel ao
juntar na branch `main`.
