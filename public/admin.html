Cadastrar vendedor de loja

O vendedor entra em Ligações das lojas com o e-mail. A primeira senha é o próprio e-mail e, no primeiro acesso, o sistema obriga a criar uma senha nova que só ele sabe. Ele vê só a lista da loja dele.
Cadastrar vários de uma vez
Uma pessoa por linha, no formato Nome; e-mail; LOJA. Lojas: .

Gerentes (veem o Dashboard das ligações)

O gerente vê a lista e o Dashboard de todas as lojas, só para acompanhar (não marca nada fora da loja dele). Se ainda não tiver acesso, o cadastro é criado com a senha = e-mail e troca obrigatória no primeiro acesso.

Acessos das Ligações

Todas as pessoas com loja ou com Dashboard. Mude a loja ou o acesso ao Dashboard direto aqui.
